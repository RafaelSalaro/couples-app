# Couples App (working title)

A couples app that protects time together: partners pause distracting apps on a shared schedule and unlock time together by scanning each other's code, asking each other, or spending minutes earned through shared challenges and kudos.

**Not about control. About being intentional and real connection.**

Status: planning complete, implementation not started.
